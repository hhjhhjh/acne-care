# README 문서 검증 기록

## 대상과 방법

2026년 11월 6일의 README 초안을 대상으로 lens-grounding의 doc 모드와 lens-fit의 auto 모드를 각각 한 번 실행했다. README의 목적은 저장소를 처음 여는 사람이 서비스 범위와 준비물을 알고 로컬 실행 및 상세 자료로 이동하도록 하는 것이다.

로컬 링크, CLI 도움말 실행, 가중치와 모델 설정의 SHA-256 일치 및 Git 공백 검사를 먼저 확인했다. 원본 결과는 [근거 검토](2026-11-06-web-readme-check/lens-grounding-1.json)와 [형식 검토](2026-11-06-web-readme-check/lens-fit-1.json)에 보관한다.

## 집계

근거 검토에는 지적이 없었다. 형식 검토의 지적은 아래와 같다. 각 항목의 source는 lens-fit이다.

- README가 실행 방법과 후속 개발 항목을 함께 담고 있어 별도 개선 계획과 범위가 겹친다.
- 기능 설명의 첫 문장에 별도 주어를 가진 관형절이 들어 있다.
- confidence를 처음 사용할 때 의미를 설명하지 않았다.

두 렌즈가 함께 지적한 항목은 없다. 지적의 원문과 상대편 계약 문구는 실제 파일에 존재함을 확인했다. 근거가 없어 제외한 지적은 없다. 이 기록은 검토 당시 관찰이며 처리 상태를 관리하지 않는다.

## 검토 범위

배정한 두 렌즈의 결과와 원칙 적용 내역을 모두 받았다. 문서 타입과 문장 구조 판정은 LLM 판단이다. 두 렌즈는 명령을 다시 실행하지 않았으며 호출자의 실행 결과와 실제 코드를 근거로 삼았다.

가독성 전용 렌즈는 별도로 제안하거나 실행하지 않았다. 이번 범위는 짧은 실행 안내의 갱신이며 기본 형식 검토에서 용어와 문장 구조를 확인했다. 렌더링 산출물이 없어 시각 검토는 적용하지 않았다. 새 방법의 효과나 실현 가능성을 주장하는 문서가 아니므로 선행연구와 주장 반박은 제안하지 않았다.
