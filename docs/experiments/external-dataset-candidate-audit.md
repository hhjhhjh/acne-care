# 외부 여드름 데이터 후보 검사

검사일은 2026년 10월 22일이다. 이 문서는 외부 데이터 후보를 `dataset-v2`에 병합하기 전에
실행한 검사의 결과를 기록한다. 후보 데이터는 아직 학습 데이터로 승인하지 않았다.

## 후보 정보

- Kaggle 식별자: `imtkaggleteam/acne-computer-vision`
- 제목: `Acne | Computer Vision`
- Kaggle 표시 라이선스: CC BY 4.0
- 로컬 원본 위치: `data/raw/candidates/acne-computer-vision/`
- 주석 형식: Roboflow CSV bounding box
- 클래스: `acne`, `pimple`, `spot`

파일 이름 일부에는 사람 이름과 직업으로 보이는 문자열이 들어 있다. 원본 데이터와 상세 검사 결과는
Git에 올리지 않는다. 보고서에는 집계 결과만 남긴다.

## 자동 검사 결과

| 분할 | 이미지 | 주석이 있는 이미지 | 상자 |
|---|---:|---:|---:|
| Train | 1,621 | 1,574 | 7,844 |
| Validation | 404 | 381 | 1,924 |
| Test | 22 | 22 | 104 |
| 합계 | 2,047 | 1,977 | 9,872 |

클래스별 상자는 `acne` 4,169개, `pimple` 643개, `spot` 5,060개다. 주석이 없는 이미지는
Train 47장과 Validation 23장으로 모두 70장이다. CSV 열, 숫자 형식, 이미지 경로, 좌표 범위에서는
구조 오류가 발견되지 않았다.

Roboflow 변환 접미사를 제거한 원본 이름을 기준으로 분할 간 충돌은 없었다. 파일 SHA-256과
64비트 dHash·aHash를 함께 사용해 `dataset-v2`와 비교했으며, 정확히 같은 이미지와 해밍 거리 6
이하의 유사 이미지는 발견되지 않았다. 지각 해시는 구도와 편집이 크게 달라진 동일 이미지를 모두
찾는 방법이 아니므로 이 결과를 동일 인물 부재의 증거로 해석하지 않는다.

## 라벨 정의와 표본 확인

Kaggle 설명은 `acne`을 붉지 않은 돌출 병변, `pimple`을 붉은 돌출 병변, `spot`을 평평하고 짙은
갈색 자국으로 정의한다. 현재 `dataset-v2`는 세부 유형을 나누지 않는 단일 `Acne` 클래스다.

고정 난수 시드 42로 클래스별 여섯 장씩 모두 18장을 뽑아 상자를 겹쳐 확인했다. `spot`에는 점,
주근깨, 색소 자국이 포함되어 현재 탐지 대상과 맞지 않았다. `acne`과 `pimple`은 활용 가능성이
있지만 일부 상자는 시각적으로 모호했고, 얼굴에 보이는 병변보다 주석 수가 적어 보이는 사례도 있었다.
따라서 세 클래스를 모두 `Acne`으로 합치는 방안은 기각한다.

## 현재 판단

후보 전체를 바로 병합하지 않는다. `pimple` 포함 이미지 25장과 `acne`만 있는 이미지 25장을
고정 시드 42로 추출해 검토 화면을 만들었다. 두 클래스를 단일 `Acne`으로 변환한 상자는 184개다.
표본은 아직 사람이 검토하지 않았으므로 병합 여부는 보류한다. 표본의 누락과 오표기 비율을 확인한
뒤 다음 조건으로 첫 실험용 데이터를 만들지 결정한다.

- 검토를 통과한 `acne`과 `pimple`만 단일 `Acne` 클래스로 변환한다.
- `spot` 상자는 학습 대상에서 제외한다.
- `spot`만 있거나 주석이 없는 이미지는 첫 병합 실험에서 제외한다.
- 후보 Train만 기존 Train에 추가한다.
- 후보 Validation과 Test는 외부 데이터 평가용으로 보존한다.
- 기존 `dataset-v2`의 Validation과 Test는 변경하지 않는다.

이 절차는 데이터 추가 효과를 기존 기준 실험과 같은 평가 집합에서 비교하기 위한 것이다.

## 50장 표본 검토 결과

사용자가 2026년 10월 22일에 검토 결과를 내보냈다. 내보낸 파일의 데이터 지문은
`4ef1e314890b`이며 생성한 50장 표본과 일치한다. 사용자의 후속 판단에 따라 처음에 미검토로
남은 한 장도 `needs_correction`으로 확정했다.

| 표본 그룹 | 정상 | 수정 필요 | 미검토 | 합계 |
|---|---:|---:|---:|---:|
| `acne`만 포함 | 18 | 7 | 0 | 25 |
| `pimple` 포함 | 12 | 13 | 0 | 25 |
| 합계 | 30 | 20 | 0 | 50 |

전체 표본의 40%인 20장에서 라벨 수정이 필요했다. `pimple` 그룹은 25장 중 13장에서 수정이
필요해 `acne`만 포함한 그룹보다 오류 비율이 높았다. 검토 메모는 주로 이마,
볼, 코, 턱의 누락 병변을 가리켰다. 이 결과만으로 전체 후보의 정확한 오류율을 단정하지는 않지만,
후보 라벨을 그대로 학습 데이터에 넣기에는 오류가 많다는 판단 근거로 충분하다.

원본 검토 JSON에는 사람 이름으로 보이는 파일명이 들어갈 수 있으므로 Git에서 제외된
`runs/dataset-audit/external-candidate-review/review-2026-10-22.json`에 보관한다. 상태 집계와 파일
해시는 [`external-dataset-label-review-summary.json`](external-dataset-label-review-summary.json)에
기록했다. 발표 자료용 화면은

검토는 모두 끝났지만 오류 비율이 높으므로 후보 전체 병합은 보류한다.
