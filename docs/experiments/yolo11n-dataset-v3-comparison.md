# YOLO11n dataset-v2·v3 비교

2026년 11월 10일, 두 모델을 같은 `dataset-v3` Test 354장에서 비교했다. v3 모델은 전체 F1을
0.422에서 0.536으로 높이고, 사진 한 장당 탐지 개수의 평균 절대 오차(Count MAE)를 2.282개에서
1.718개로 줄였다. 개선은 외부 데이터에서 컸다. 기존 사진 47장에서는 F1이 낮아지고 개수 오차가 늘었다.

## 데이터와 평가 방법

`dataset-v3`는 기존 `dataset-v2` 분할을 유지하고 검토한 라벨을 적용한 외부 데이터를 추가한다.
[분할 코드](../../ml/dataset/build_dataset_v3.py)는 파일명과 이미지 유사도를 기준으로 묶은 외부
이미지를 같은 분할에 넣는다. 동일 인물이 여러 분할에 들어갔는지는 검증하지 않았다.

| 데이터 | Train | Validation | Test |
|---|---:|---:|---:|
| 기존 | 823 | 54 | 47 |
| 외부 | 1,433 | 307 | 307 |
| 전체 | 2,256 | 361 | 354 |

v3 모델은 RTX A5000에서 `yolo11n.pt`로 시작해 640×640, 배치 8, 시드 42, 50 epoch,
기본 증강(`control`)으로 학습했다. 두 모델의 탐지 신뢰도 기준값은 공통 Validation 361장에서
각각 선택했으며 둘 다 0.25였다. F1이 가장 높은 값을 고르고, 동률이면 Count MAE가 작고
Recall이 높은 값을 우선했다. Test에는 선택한 기준값을 적용했다. F1과 Count MAE는 이미지별
예측으로 집계했으며, F1을 계산할 때는 탐지 상자와 정답 상자의 겹침 비율(IoU) 0.5를 적용했다.

## Test 결과

| 평가 범위 | 모델 | F1 | Count MAE | mAP50–95 |
|---|---|---:|---:|---:|
| 전체 354장 | v2 | 0.422 | 2.282 | 0.150 |
| 전체 354장 | v3 | 0.536 | 1.718 | 0.217 |
| 기존 47장 | v2 | 0.652 | 3.468 | — |
| 기존 47장 | v3 | 0.643 | 3.957 | — |
| 외부 307장 | v2 | 0.140 | 2.101 | — |
| 외부 307장 | v3 | 0.435 | 1.375 | — |

전체 Test의 Recall은 33.9%에서 48.1%로 올랐다. 정답 상자 1,386개 가운데 놓친 상자가
916개에서 720개로 줄었고, 정답과 대응하지 않는 예측 상자는 372개에서 432개로 늘었다.
외부 Test 307장 중 사람이 라벨을 검토한 사진은 89장이다. 외부 라벨 검토 범위와 기존 사진의
성능 저하를 함께 고려해, v3를 웹 서비스에서 검증할 후보로 삼는다.

[집계 JSON](yolo11n-dataset-v3-comparison.json)에 모델 가중치의 위치와 SHA-256, Validation 기준값
선택 결과, 분할별 Test 지표를 기록했다. 이미지와 라벨, 가중치, 이미지별 예측은 로컬에 보관한다.
