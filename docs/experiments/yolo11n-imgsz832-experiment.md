# YOLO11n 입력 크기 832 대조 실험

## 결론

입력 크기를 640에서 832로 높였지만 Validation 성능은 개선되지 않았다. 전체 F1과 mAP가
낮아졌고 개선 목표였던 작은 병변 Recall도 0.519에서 0.481로 낮아졌다. 832 모델은 채택하지
않으며 `yolo11n-dataset-v2-control-seed42`를 기준 모델로 유지한다.

Test는 실행하지 않았다. 모델 선택과 다음 실험 결정에는 Validation 54장만 사용했다.

## 대조 조건

두 모델은 YOLO11n, dataset-v2, seed 42, 50 epoch, batch size 8, patience 15와 기본 증강
설정이 같다. 입력 크기만 변경했다.

| 항목 | 기준 모델 | 해상도 실험 |
|---|---:|---:|
| 입력 크기 | 640 | 832 |
| 최고 성능 epoch | 50 | 48 |
| Validation 이미지 | 54 | 54 |
| 정답 객체 | 677 | 677 |
| 선택 threshold | 0.30 | 0.25 |

832 모델은 NVIDIA RTX A5000에서 학습했다. 가중치 SHA-256은
`5eeba4a664aa771fb72eaaa2d3395da042d0207cc805419d032d176f977d6358`이다. 가중치는
Git에 넣지 않고 `runs/experiments/yolo11n-dataset-v2-imgsz832-seed42/`에 보관한다.

## 전체 결과

| 지표 | 640 기준 모델 | 832 모델 | 변화 |
|---|---:|---:|---:|
| True Positive | 418 | 416 | -2 |
| False Positive | 209 | 233 | +24 |
| False Negative | 259 | 261 | +2 |
| Precision | 0.667 | 0.641 | -0.026 |
| Recall | 0.617 | 0.614 | -0.003 |
| F1 | 0.641 | 0.627 | -0.014 |
| Count MAE | 3.296 | 3.667 | +0.370 |
| mAP50-95 | 0.301 | 0.292 | -0.009 |
| mAP50 | 0.678 | 0.658 | -0.019 |
| mAP75 | 0.228 | 0.222 | -0.007 |

832 모델은 True Positive가 2개 줄고 False Positive가 24개 늘었다. 높은 해상도로 얻은 추가
정보가 현재 데이터와 학습 조건에서는 탐지 성능 향상으로 이어지지 않았다.

## 객체 크기별 결과

| 크기 | 정답 객체 | 640 Recall | 832 Recall | 변화 | 832 모델 누락 |
|---|---:|---:|---:|---:|---:|
| Small | 216 | 0.519 | 0.481 | -0.037 | 112 |
| Medium | 452 | 0.664 | 0.677 | +0.013 | 146 |
| Large | 9 | 0.667 | 0.667 | 0.000 | 3 |

Medium에서는 6개를 더 찾았지만 Small에서는 8개를 더 놓쳤다. 작은 병변 개선이라는 실험 목적을
달성하지 못했다. Large는 정답이 9개뿐이므로 별도 결론을 내리지 않는다.

## 판단

다음 학습은 입력 크기를 640으로 되돌린다. 추가 실험에서는 한 가지 증강 설정만 바꾸고 동일한
Validation 절차로 비교한다. 832 모델은 Test로 평가하지 않는다.

상세한 이미지별 결과는 Git에서 제외한
`runs/error-analysis/yolo11n-dataset-v2-imgsz832-val.json`에 보관한다.
