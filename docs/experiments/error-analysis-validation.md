# Validation 오류 분석: acne-CV와 YOLO11n

## 결론

YOLO11n은 기존 acne-CV 모델보다 병변을 더 많이 찾는다. 특히 작은 병변 Recall이 크게 올랐다. 다만 False Positive도 함께 늘었다. 다음 실험에서는 무작정 증강 종류를 늘리기보다 라벨 품질을 먼저 확인하고, 작은 병변을 위한 입력 해상도 실험을 진행하는 편이 적절하다.

Clean test 47장은 이 분석과 개선 방향 선택에 사용하지 않았다. 모든 비교에는 Validation 56장과 각 모델에서 미리 선택한 confidence threshold를 사용했다.

## 비교 조건

| 항목 | 기존 acne-CV | YOLO11n 기준 모델 |
|---|---:|---:|
| 모델 | KerasCV YOLOv8 XS | Ultralytics YOLO11n |
| confidence threshold | 0.30 | 0.20 |
| IoU threshold | 0.50 | 0.50 |
| Validation 이미지 | 56장 | 56장 |
| 정답 객체 | 643개 | 643개 |

## 전체 결과

| 지표 | 기존 acne-CV | YOLO11n | 차이 |
|---|---:|---:|---:|
| True Positive | 343 | 383 | +40 |
| False Positive | 196 | 253 | +57 |
| False Negative | 300 | 260 | -40 |
| Precision | 63.64% | 60.22% | -3.42%p |
| Recall | 53.34% | 59.56% | +6.22%p |
| F1 | 58.04% | 59.89% | +1.85%p |

두 모델이 함께 찾은 객체는 286개였다. YOLO11n만 찾은 객체는 97개였고 기존 모델만 찾은 객체는 57개였다. 두 모델이 모두 놓친 객체는 203개로 전체 정답의 31.57%였다.

YOLO11n은 탐지 범위를 넓혀 Recall을 높였다. 그 대가로 False Positive가 29.08% 늘어 Precision이 낮아졌다. 따라서 다음 개선 목표는 작은 병변 Recall을 유지하면서 False Positive를 줄이는 것이다.

## 객체 크기별 결과

객체 크기는 640×640 좌표에서 COCO 기준을 적용했다. small은 면적이 `32²` 미만이고 medium은 `32²` 이상 `96²` 미만이다.

| 크기 | 정답 수 | 기존 Recall | YOLO11n Recall | 차이 |
|---|---:|---:|---:|---:|
| small | 205 | 35.61% | 48.78% | +13.17%p |
| medium | 429 | 61.77% | 65.03% | +3.26%p |
| large | 9 | 55.56% | 44.44% | -11.11%p |

가장 분명한 개선은 작은 병변에서 나타났다. 그럼에도 YOLO11n은 작은 병변 205개 중 105개를 놓쳤다. large는 정답이 9개뿐이므로 이 결과만으로 성능 저하를 판단할 수 없다.

## 촬영 조건별 결과

밝기와 선명도는 이미지별 측정값을 기준으로 56장을 각각 세 그룹으로 나눴다. 각 그룹의 이미지와 병변 구성이 다르므로 이 수치는 원인을 증명하지 않는다.

| 조건 | 낮은 그룹 Recall | 중간 그룹 Recall | 높은 그룹 Recall |
|---|---:|---:|---:|
| 밝기 | 56.68% | 65.20% | 57.41% |
| 선명도 | 65.96% | 55.80% | 59.35% |

밝기가 중간인 그룹에서 YOLO11n Recall이 가장 높았다. 어둡거나 밝은 그룹에서는 약 8%p 낮았다. 다만 선명도가 낮은 그룹의 Recall은 오히려 가장 높았다. 현재 결과로는 blur 증강을 우선할 근거가 없고, 밝기 증강은 후속 대조 실험 후보로만 남긴다.

## 위치 정확도

| IoU 기준 | 기존 Recall | YOLO11n Recall |
|---|---:|---:|
| 0.30 | 59.41% | 65.01% |
| 0.50 | 53.34% | 59.56% |
| 0.75 | 25.04% | 31.42% |

YOLO11n의 Recall은 IoU 0.30에서 0.50으로 높였을 때 5.44%p 감소했다. 위치가 조금 어긋난 탐지도 일부 있지만, IoU 0.50에서 놓친 260개 전체를 위치 오차만으로 설명할 수는 없다.

## 대표 실패 사례에서 확인한 점

오버레이에서 초록색은 True Positive, 빨간색은 False Positive, 하늘색은 False Negative를 뜻한다. `runs/error-analysis/overlays/`에 생성되며 Git에는 포함하지 않는다.

- 정답이 많은 이미지에서 작은 병변을 연속으로 놓치는 사례가 반복되었다. `acne-6`, `acne-224`, `acne-237`이 대표적이다.
- `acne-373`과 `acne-90`에서는 YOLO11n의 False Positive가 각각 10개였다. 시각적으로 병변처럼 보이지만 라벨이 없는 위치도 여러 곳에 있었다.
- 일부 빨간 상자와 하늘색 상자가 가까이 겹쳤다. 이는 병변 존재 여부보다 상자 위치와 크기가 달라 IoU 0.50을 넘지 못한 사례다.
- 위 관찰만으로 라벨 오류를 확정할 수는 없다. 라벨에 포함할 병변의 범위와 상자 작성 방식이 일관적인지 사람이 원본을 다시 확인해야 한다.

## 이미 적용된 증강

현재 기준 모델은 Ultralytics 기본 학습 설정을 사용했다. 학습 기록에는 HSV 색상 변화, 좌우 반전, 이동, 확대·축소, mosaic가 이미 적용되어 있다. 같은 증강을 단순히 다시 추가하는 것은 새로운 실험이 아니다. 위아래 반전은 얼굴 방향을 비현실적으로 바꾸므로 우선순위에서 제외한다.

## 권장 실험 순서

### 라벨 감사와 기준 고정

False Positive와 False Negative가 많은 이미지 20장 안팎을 먼저 검토한다. 병변 종류의 포함 기준, 매우 작은 병변의 최소 크기, 겹친 병변의 상자 작성 방법을 문서로 고정한다. 실제 병변인데 라벨이 빠진 사례가 많다면 학습 설정을 바꾸기 전에 데이터 버전을 새로 만들어야 한다.

### 입력 해상도 대조 실험

YOLO11n과 나머지 학습 조건을 유지하고 입력 크기만 640에서 832로 바꾼다. 작은 병변 Recall, 전체 Precision, F1, 추론 시간을 같은 Validation에서 비교한다. 작은 병변이 현재 가장 큰 성능 공백이므로 이 실험이 첫 모델 개선 후보다.

### 증강 대조 실험

라벨 감사와 해상도 실험 뒤에 한 변수씩 비교한다. 밝기 변화 범위를 조정한 실험과 mosaic 강도를 낮춘 실험을 각각 따로 진행한다. 기본 설정에 이미 포함된 좌우 반전과 확대·축소를 별도 근거 없이 더 강하게 적용하지 않는다.

### False Positive 억제 실험

라벨이 정상인데도 피부결, 점, 모공을 여드름으로 검출한다면 해당 사례를 학습 데이터에 충분히 포함하고 hard negative로 관리한다. confidence threshold를 다시 조정하는 일은 새 모델을 학습한 뒤 Validation에서 수행한다.
