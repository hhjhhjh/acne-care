# acne-care

얼굴 사진에서 여드름을 탐지하고 얼굴 부위별 분포와 시간에 따른 변화를 보여 주는 대학 수업 프로젝트이다. 의료 진단이나 질환 판정을 제공하지 않는다.

## 현재 상태

이전 프로젝트인 `acne-CV`의 모델을 격리된 호환 환경에서 복원하고 Kaggle 데이터의 정제된 test 이미지 47개로 평가했다. 이전 모델은 비교 기준으로만 유지하며, 새 기능은 프레임워크에 의존하지 않는 도메인 모듈과 인터페이스에 구현한다. 이전 웹 코드는 제품 코드로 직접 연결하지 않았다.

## 이전 프로젝트 자료

- [재사용 조사 결과](docs/legacy-acne-cv-audit.md)에서 `acne-CV`의 중복 폴더와 파일별 판정을 확인할 수 있다.
- [이전 모델 자료](references/acne-cv/README.md)에서 모델 구조, 얼굴 부위 인덱스와 주의 사항을 확인할 수 있다.
- [모델 관리 안내](models/README.md)에 따라 검증된 기존 가중치를 로컬로 가져올 수 있다.
- [데이터 관리 안내](data/README.md)에 Kaggle 데이터셋의 출처와 저장 규칙을 적어 두었다.
- [이전 모델 평가](docs/experiments/legacy-baseline.md)에 측정 조건, 결과와 해석을 적어 두었다.

## 다음 개발 목표

다음 구현 목표는 현재 관리되는 YOLO 구현으로 학습 가능한 새 baseline을 만들고 이전 모델과 같은 비교 집합에서 평가하는 것이다. 이후 얼굴 영역 판정과 변화 추적은 탐지기 구현과 분리된 모듈로 추가한다.

## 주의 사항

얼굴 사진, 다운로드한 데이터셋, 데이터베이스와 모델 가중치는 기본 Git 추적 대상에서 제외한다. 얼굴 부위와 신체 장기의 건강 상태를 연결했던 이전 프로젝트의 문구는 의학적 근거를 확인하지 못했으므로 재사용하지 않는다.
